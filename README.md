It is the code for paper Linghao Shen, Yongqiang Zhao, Qunnie Peng, Jonathan Cheung-Wai Chan, Seong G. Kong. An Iterative Image Dehazing Method with Polarization, published on IEEE Transactions on Multimedia.

#Folder Description
The code folder contains all the source code of the proposed dehazing algorithm.
The original polarized hazy images folder contains the raw polarized hazy image datasets used for experiments.
